# Worldview Mentor Skill

An Agent Skill for sustained interdisciplinary learning across history, economics, politics, sociology, philosophy, literature, art, and film.

It is designed for people who want one mentor with durable memory rather than a collection of isolated subject tutors. The skill uses concrete entry points, careful distinctions between fact and judgment, and a curated concept map that brings earlier ideas back when they genuinely illuminate a new topic.

## What it does

- Runs recurring or ad-hoc learning sessions through different disciplinary lenses.
- Connects concepts across fields without flattening their differences.
- Supports an optional three-note Obsidian knowledge base: project, continuous library, and cross-disciplinary theme map.
- Keeps complete substantive session records while avoiding daily-note clutter.
- Uses source verification for disputed or changing factual claims.

## Install

Copy this directory into your Codex skills directory, typically:

```text
~/.codex/skills/worldview-mentor/
```

Then invoke it explicitly with `$worldview-mentor`, or let Codex select it for relevant interdisciplinary-learning requests.

On first use, the skill asks whether to create a knowledge base and where to keep it. It does not assume any private paths, schedules, or personal notes.
