# Worldview Project

## Purpose

Develop a connected and revisable understanding of history, economics, politics, sociology, philosophy, literature, art, and film. Favor depth, comparisons with real explanatory value, and durable questions over coverage for its own sake.

## Default weekly rhythm

| Day | Primary lens |
| --- | --- |
| Monday | Culture: literature, art, or film |
| Tuesday | Economic life: markets, institutions, inequality, finance, and work |
| Wednesday | Philosophy: concepts, arguments, and lived dilemmas |
| Thursday | Public world: political science or sociology |
| Friday | History: events, institutions, sources, and interpretations |

The rhythm is a way to revisit common questions from different angles, not five separate curricula.

## Recording rules

- Append substantive conversations to `Worldview Library.md`.
- Update `Cross-disciplinary Theme Map.md` only when a concept genuinely recurs across domains, becomes a durable question, or revises a prior judgment.
- Do not create daily notes, per-session notes, trivia cards, or a separate notebook for every discipline.

## Continuation

At the start of a session, read this note, recent Library entries, the Theme Map, and only the notes directly relevant to the current question. State any meaningful callback briefly before teaching.
